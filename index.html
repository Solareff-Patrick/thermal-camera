One-time setup: give the browser access to the camera

  1. Plug the camera into the phone's USB-C port. Use a USB-C OTG adapter if the camera's plug doesn't fit.
  2. If Android asks which app should open the device, dismiss the prompt or choose Chrome.
  3. Tap Connect camera, pick PIR206 Thermal Camera and allow access.

Use Chrome on Android. You don't need to install a driver. To add the app to your home screen, open Chrome's ⋮ menu and choose Add to Home screen (or Install app).

Windows doesn't install a driver for this camera's USB interface, so the browser can't reach it until the generic WinUSB driver is bound to it:
  1. Download Zadig from zadig.akeo.ie and run it (admin prompt).
  2. Menu Options → List All Devices.
  3. In the dropdown pick iAP Interface (USB ID 289D 0010 00). Not com.thermal.pir206.1.
  4. Target driver WinUSB, then click Install Driver.
  5. Unplug and replug the camera, reload this page, and click Connect camera.

This only affects this camera. You can roll it back in Device Manager → Uninstall device (tick “delete driver”). Use Chrome or Edge: WebUSB isn't available in Firefox or Safari.

Temperature calibration

The Compact reports raw sensor counts, so temperatures are estimates until you calibrate. Aim at something of known temperature, such as ice water (0 °C) or a matte-taped surface measured with a probe. Pin it, enter its temperature and press Set point. One point corrects the offset. A second point at a different temperature corrects the scale too.

Image correction

Removes the fixed pattern and vignetting. Cover the lens with something of even temperature, such as a matte card or your palm, then click Capture.
